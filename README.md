# finance-ai-assistant

A finance assistant on **100% fake data**, built step by step to learn AI engineering in Python: FastAPI, LLM calls, structured outputs, tool calling, RAG, agents, MCP, evals and deploy.

> Study project, work in progress. See [docs/ROADMAP.md](docs/ROADMAP.md).

## How to run

```bash
uv sync
uv run uvicorn finance_ai_assistant.main:app --reload
```

Open http://localhost:8000/docs
